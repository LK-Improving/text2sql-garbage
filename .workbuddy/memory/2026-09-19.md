# 2026-09-19

## Netlify 部署改为分支闸门模型
- 用户把 Netlify Production branch 改成 `main`。日常开发在 `master`，发版时 `git merge master` 进 `main` 再 `git push origin main` 才触发构建。
- 等价于用分支控制部署时机，自动部署保持开启但不再每次提交都 build（省构建分钟/积分）。GitHub 默认分支仍是 `master`。
- 命令（每次发版）：`git checkout main && git pull origin main && git merge master && git push origin main`。
  首次若本地/远程无 `main`：`git checkout -b main origin/main`（或 `git branch main && git push -u origin main`）。
- 已记进 MEMORY.md 部署分支模型约定。

## 左侧「会话管理」做成真功能
- 之前 Sidebar 的「历史对话」只是把当前单次会话的 turns 倒序展示，点「新建对话 / 历史项」都只弹「暂未开放」toast——是假功能。
- 本次重构为真正的多会话模型：新增 `Conversation` 类型（id/title/turns/createdAt/updatedAt）；
  `page.tsx` 的 `turns` 状态升级为 `conversations[]` + `activeId`，`ask`/重跑/多轮上下文都按 active 会话定位；
  `Sidebar` 会话列表支持**新建 / 切换 / 删除（有内容先 confirm）/ 重命名（行内 input）**；`TopBar` 面包屑显示当前会话标题。
- 持久化：`localStorage` 的 `t2s.conversations` + `t2s.activeId`，防抖 400ms 写入（避免流式输出高频写）；
  挂载时恢复，active 失效自动回落到首个会话。
- 改动 5 个文件：types.ts / icons.tsx（加 IconTrash/IconEdit）/ Sidebar.tsx / TopBar.tsx / page.tsx。
  `tsc --noEmit` 与 `next build`（Turbopack）均通过。改动只提交到 `master`，等用户 `git release`（merge master→main）才上生产。
