# 2026-09-19

## Netlify 部署改为分支闸门模型
- 用户把 Netlify Production branch 改成 `main`。日常开发在 `master`，发版时 `git merge master` 进 `main` 再 `git push origin main` 才触发构建。
- 等价于用分支控制部署时机，自动部署保持开启但不再每次提交都 build（省构建分钟/积分）。GitHub 默认分支仍是 `master`。
- 命令（每次发版）：`git checkout main && git pull origin main && git merge master && git push origin main`。
  首次若本地/远程无 `main`：`git checkout -b main origin/main`（或 `git branch main && git push -u origin main`）。
- 已记进 MEMORY.md 部署分支模型约定。
