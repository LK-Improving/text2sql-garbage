SELECT v.plate_number, r.region_name, a.alert_type, a.alert_time FROM t_alert a JOIN t_vehicle v ON a.vehicle_id = v.id LEFT JOIN t_region r ON v.region_id = r.id WHERE a.alert_type = '超速' AND a.alert_time >= CURRENT_DATE - INTERVAL '3 days' ORDER BY a.alert_time DESC LIMIT 1000

### F01 · 综合查询 · false_reject
- 问题：这个月既有超速预警、清运量又排前 5 的车
- 说明：SQL 安全校验不通过: 不允许访问的表：ranked、month_alert（白名单：t_region、t_vehicle、t_route_manifest、t_alert、t_weigh_bill）
- 生成的 SQL：```sql
WITH month_manifest AS (
  SELECT rm.vehicle_id,
         SUM(rm.total_weight) AS total_weight
  FROM t_route_manifest rm
  WHERE rm.route_date >= date_trunc('month', CURRENT_DATE)
    AND rm.route_date < date_trunc('month', CURRENT_DATE) + INTERVAL '1 month'
  GROUP BY rm.vehicle_id
),
ranked AS (
  SELECT vehicle_id,
         total_weight,
         RANK() OVER (ORDER BY total_weight DESC) AS weight_rank
  FROM month_manifest
),
month_alert AS (
  SELECT vehicle_id,
         COUNT(*) AS alert_cnt
  FROM t_alert
  WHERE alert_type = '超速'
    AND alert_time >= date_trunc('month', CURRENT_DATE)
    AND alert_time < date_trunc('month', CURRENT_DATE) + INTERVAL '1 month'
  GROUP BY vehicle_id
)
SELECT v.plate_number,
       r.region_name,
       rk.weight_rank,
       rk.total_weight,
       ma.alert_cnt
FROM ranked rk
JOIN month_alert ma ON ma.vehicle_id = rk.vehicle_id
JOIN t_vehicle v ON v.id = rk.vehicle_id
LEFT JOIN t_region r ON r.id = v.region_id
WHERE rk.weight_rank <= 5
ORDER BY rk.weight_rank
LIMIT 1000
```
- 错误：SQL 安全校验不通过: 不允许访问的表：ranked、month_alert（白名单：t_region、t_vehicle、t_route_manifest、t_alert、t_weigh_bill）
