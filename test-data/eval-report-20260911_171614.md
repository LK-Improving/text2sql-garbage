### F01 · 综合查询 · mismatch
- 问题：这个月既有超速预警、清运量又排前 5 的车
- 说明：结果不一致：实际 4 行 5 列 / 期望 5 行 2 列
- 生成的 SQL：```sql
WITH monthly AS (
  SELECT rm.vehicle_id,
         SUM(rm.total_weight) AS total_weight,
         RANK() OVER (ORDER BY SUM(rm.total_weight) DESC) AS rk
  FROM t_route_manifest rm
  WHERE rm.route_date >= date_trunc('month', CURRENT_DATE)
    AND rm.route_date < date_trunc('month', CURRENT_DATE) + INTERVAL '1 month'
  GROUP BY rm.vehicle_id
)
SELECT v.plate_number,
       r.region_name,
       m.total_weight,
       m.rk,
       COUNT(a.id) AS alert_times
FROM monthly m
JOIN t_vehicle v ON v.id = m.vehicle_id
LEFT JOIN t_region r ON r.id = v.region_id
JOIN t_alert a ON a.vehicle_id = v.id
  AND a.alert_type = '超速'
  AND a.alert_time >= date_trunc('month', CURRENT_DATE)
  AND a.alert_time < date_trunc('month', CURRENT_DATE) + INTERVAL '1 month'
WHERE m.rk <= 5
GROUP BY v.plate_number, r.region_name, m.total_weight, m.rk
ORDER BY m.total_weight DESC
LIMIT 1000
```
